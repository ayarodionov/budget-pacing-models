# Instructions for Claude

Models of budget pacing: a center must spend a budget B over a time T without
overspending, steering an unknown number of clients only through a broadcast
probability p. Start with [README.md](README.md); the shared model is
[models/system.md](models/system.md).

## Install

Requirements: [uv](https://docs.astral.sh/uv/) (Python 3.13 is installed by uv
from `.python-version`). For the Elixir part: Elixir ≥ 1.19 with Erlang/OTP ≥ 28,
and a C compiler (`cc`) for the NIF.

```bash
uv sync                      # creates .venv with numpy, scipy, matplotlib, pytest
make -C elixir               # builds elixir/priv/pacing_math_nif.so (optional; tests run without it)
```

## Check that everything works

Run these first, before changing anything. All must pass.

```bash
uv run pytest -q             # Python: about 175 tests, ~35 s
make -C elixir test          # Elixir: 4 suites (math, controller, token cap, registration), ~10 s
uv run python -m pacing.scenario_file scenarios/minimal.toml   # one end-to-end run, a few seconds
```

Without a C compiler, test pure Elixir only:
`cd elixir && elixir -r pacing_math.ex pacing_math_test.exs`.

## Where things are

| Path | What |
|---|---|
| `models/` | the model descriptions: `system.md` (shared), `probabilistic.md`, `token-cap-a.md`, `token-cap-b.md`, `implementation.md`, `initialmodel.md` (the original problem) |
| `models/seasonal/` | the same models for traffic that varies by hour and weekday |
| `results/` | generated by the experiment scripts; do not edit by hand |
| `src/pacing/` | Python: `model.py` (simulator), `controllers.py`, `backstop.py` (token caps), `seasonal.py`, `scenario_file.py`, `experiments.py`, `seasonal_experiments.py`, `overview.py`, `specfun.py` |
| `elixir/` | the production-side port: `PacingController`, `TokenCap`, `PacingCenter`, `PacingClient`, math kernel and NIF; see `elixir/README.md` |
| `scenarios/` | scenario files: `minimal.toml` (required fields only), `example.toml` (every field, commented) |
| `scripts/` | generators of the Elixir golden tests from the Python reference |
| `tests/` | Python tests |

Simulation parameters, required and optional: `models/system.md` §8.

## Running experiments

```bash
uv run python -m pacing.experiments            # probabilistic controller, ~16 min (--quick: ~1.5 min)
uv run python -m pacing.backstop               # token caps (a) and (b), ~7 min (--quick: ~1 min)
uv run python -m pacing.overview               # README comparison chart, ~80 s
uv run python -m pacing.seasonal_experiments   # seasonal models, ~8 min (--quick: ~1 min)
uv run python -m pacing.scenario_file FILE     # a scenario file -> results/scenarios/
```

Run long experiments in the background. A `--quick` run overwrites the results
files with low-precision numbers: always finish with a full run before using or
committing numbers.

## Rules for changes

- **Keep the base results bit-identical.** New options must default to the old
  behaviour. After changing `model.py`, `controllers.py` or `backstop.py`, check
  that existing results are unchanged: regenerate the Elixir golden files (below)
  and confirm `git diff` shows no change to them, and compare the results tables
  with the committed ones.
- **Python is the reference; Elixir must match it.** After changing a controller
  or the token cap in Python, regenerate the golden files and run the Elixir tests:

  ```bash
  uv run python scripts/gen_elixir_controller_golden.py
  uv run python scripts/gen_elixir_token_cap_golden.py
  uv run python scripts/gen_elixir_golden.py && (cd elixir && mix format pacing_math_test.exs)
  make -C elixir test
  ```
- **Numbers in the docs come from full runs**, never from quick ones, and must be
  checked against the results files. Overspend rates near ε need many runs: a
  rate from a few hundred runs is noise.
- **Check charts by looking at them** (read the PNG) before describing them.
- **Check links** after moving or renaming files: all relative links in `*.md`
  must resolve, with exact case (GitHub is case-sensitive, macOS is not).
- **Format Elixir** with `mix format` on the changed files.
- **Commit and push only when the user asks.**
